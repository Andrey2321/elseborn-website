ELSEBORN v10 — ИКОНКА ВКЛАДКИ
1. Распакуйте ZIP.
2. Загрузите ВСЕ файлы из папки elseborn-website-main в корень GitHub репозитория с заменой старых.
3. Дождитесь публикации GitHub Pages.
4. Закройте вкладку elseborn.ru и откройте сайт заново. Если иконка старая, попробуйте окно инкогнито.
5. В браузере проверьте https://elseborn.ru/favicon-32.png?v=elseborn-v10

Внутри архива favicon.ico с размерами 16, 32, 48, 64, 128, 256, favicon-32.png, favicon-192.png, apple-touch-icon.png. Иконки созданы из утверждённого прозрачного логотипа.
