ELSEBORN — исправление публичных профилей v3

Причина: app.js, community.js и profile-extra.js создавали ТРИ клиента Supabase с одним ключом сессии.
Теперь все три модуля импортируют один клиент из supabase-client.js.
Запросы к базе и сессии ограничены по времени; вместо вечной «Загрузка...» показывается ошибка.

УСТАНОВКА:
1. Распаковать ZIP.
2. Загрузить файлы из папки elseborn-website-main в корень GitHub-репозитория с заменой.
3. ВАЖНО: добавить новый файл supabase-client.js.
4. Дождаться GitHub Pages и обновить Ctrl+Shift+R.
5. Повторно SQL выполнять НЕ НУЖНО.

Аватары и баннеры: файлы должны быть реально загружены владельцем профиля в bucket profile-images и быть доступны для чтения. Если URL отсутствует или файл недоступен, показывается запасное изображение.

Изменения проверены статически по исходникам, не на действующей базе Supabase.
