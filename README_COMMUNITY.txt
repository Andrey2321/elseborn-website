ELSEBORN COMMUNITY v1

1. Загрузить все файлы в корень GitHub Pages (папка assets тоже нужна).
2. Supabase -> SQL Editor -> New query -> вставить COMMUNITY_SETUP.sql -> Run.
3. Дождаться GitHub Pages deploy и открыть /users.html.
4. Публичные профили /public-profile.html?id=UUID.
5. Вход обязателен для оценок. Нельзя оценить себя. Одна оценка на человека (можно изменить).
6. Онлайн = активность в последние 2 минуты, при работающем heartbeat.
7. Логотип находится в assets/elseborn-logo.png.
8. Если сайт отдаёт старую версию, проверить GitHub Pages -> Build and deployment -> branch/folder.

Примечание: это сборка на основе имеющейся локальной версии Elseborn v6, а не проверенный снимок текущего GitHub. Сделайте резервную копию репозитория перед заменой.
