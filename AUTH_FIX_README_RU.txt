ELSEBORN — исправление входа и профиля (26.10.2026)

ПРОБЛЕМА: в profile.html отсутствовали элементы auth-register-extra, auth-reset, auth-consent и auth-password-confirm, к которым обращался app.js. Из-за этого возникали ошибки null и прерывалась инициализация входа.

ИСПРАВЛЕНО:
1. Полная форма авторизации на profile.html, включая восстановление пароля и подтверждение регистрации.
2. Проверки на наличие элементов в app.js для защиты от ошибок null.
3. Обновлены версии app.js во всех HTML для очистки кэша.
4. После успешного входа на странице профиля выполняется переход на profile.html.

УСТАНОВКА:
1. Открой GitHub -> Andrey2321/elseborn-website.
2. Замени файлы app.js и profile.html из этого архива в корне репозитория (остальные файлы можно оставить без изменений).
3. Подожди 1–3 минуты после публикации GitHub Pages.
4. Открой https://elseborn.ru/profile.html и нажми Ctrl+Shift+R.
5. Нажми «Войти», введи подтвержденную почту и пароль.

ВАЖНО: исправление устраняет конкретные ошибки JavaScript на скриншоте. Если вход все равно не работает, проверь сообщение в окне и Console; настройки Supabase/базы могут требовать отдельного исправления.
