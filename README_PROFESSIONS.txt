ELSEBORN — ОБНОВЛЕНИЕ ПРОФЕССИЙ

1. Распакуйте ZIP.
2. В репозитории GitHub загрузите ВСЕ файлы из архива с сохранением папки assets.
3. После публикации откройте https://elseborn.ru/forum.html → Профессии.

Новые файлы: professions.html, profession.html, professions.css, professions.js, professions-content.js, assets/profession-*.webp.
Обновлён forum.html: ссылка «Профессии» теперь открывает каталог.

ИЗМЕНЕНИЕ ТЕКСТОВ:
Откройте professions-content.js. У каждой профессии поля:
name — название; subtitle — подзаголовок; intro — краткий текст;
story — история; duties — список занятий; role — значение в мире.

Существующая таблица posts и SQL не изменялись.
«Выбор профессии» означает открытие описания, НЕ запись профессии в профиль игрока.
Игровые бонусы и правила назначения профессий пока не реализованы.
