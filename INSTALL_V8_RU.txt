ELSEBORN PROFILE V8 — УСТАНОВКА

1. Создайте резервную копию репозитория.
2. В корень GitHub Pages загрузите СОДЕРЖИМОЕ этого архива (не вложенную папку). Убедитесь, что в корне лежат profile.html, profile-v8.css, profile-v8.js.
3. Supabase > SQL Editor: выполните содержимое PROFILE_FRIENDS_SETUP.sql, если ещё не выполняли его для v7. Скрипт создаёт friend_requests и bio.
4. Дождитесь успешной публикации GitHub Pages. Откройте https://elseborn.ru/profile.html?v=8 и обновите Ctrl+Shift+R.
5. Для проверки новой версии: в консоли браузера введите document.body.dataset.elsebornProfile. Должно быть 'v8'.
6. Откройте вкладку «Достижения»: все 5 уровней считаются по profiles.created_at, включая дату регистрации. Для первого месяца и далее учитываются полные календарные месяцы.
7. Друзья работают после SQL и требуют второй аккаунт для проверки заявок.

Ограничения: Discord OAuth ещё не подключён. В этой версии реализована именно переработка дизайна личного кабинета и видимые достижения. Проверка живой базы и опубликованного домена требует установки файлов.
