ELSEBORN — исправление анимации главной страницы

Заменены только index.html и style.css. Остальные файлы сохранены.
Анимация работает через CSS без конкурирующего JavaScript.

Как обновить:
1. Распакуйте архив.
2. Загрузите содержимое папки elseborn-website-main в корень репозитория GitHub Pages, сохранив структуру.
3. Дождитесь завершения публикации GitHub Pages.
4. Откройте https://elseborn.ru/index.html и обновите страницу Ctrl+Shift+R.

При включённой системной настройке «Уменьшить движение» анимации не показываются.
