ELSEBORN COMMUNITY v2

1. Сохраните резервную копию репозитория.
2. Загрузите содержимое архива в корень GitHub репозитория, заменив одноименные файлы.
3. В Supabase Dashboard -> SQL Editor -> New query вставьте COMMUNITY_REPAIR_v2.sql и нажмите Run.
4. Дождитесь публикации GitHub Pages, откройте сайт с Ctrl+Shift+R.
5. Проверьте публичный профиль и рейтинг.

Если аватар/баннер не видны: загрузите их заново через Мой профиль, убедитесь в сообщении об успешном сохранении.
В консоли браузера ошибки Supabase помогут диагностировать отсутствующие права.
Система не раскрывает email в публичном профиле.
