ELSEBORN ACCOUNT v11 — УСТАНОВКА

ВАЖНО: Сначала резервная копия сайта и базы Supabase. Не удаляйте auth.users и profiles.
1. GitHub: замените содержимое корня репозитория содержимым этого архива.
2. Supabase > SQL Editor: выполните СОДЕРЖИМОЕ ACCOUNT_MIGRATION_v11.sql.
3. Supabase > Edge Functions: разверните функцию login-by-nickname из supabase/functions/login-by-nickname/index.ts.
   Потребуются стандартные переменные SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY.
   НЕ размещайте service role key в GitHub, браузере или клиентском лаунчере.
4. Supabase Auth > URL Configuration: добавьте https://elseborn.ru/account-password.html в Redirect URLs.
5. В Auth оставьте подтверждение email включённым. Для старых Google-аккаунтов: укажите почту в форме входа, нажмите «Забыли пароль?», откройте письмо и установите пароль.
6. Проверьте вход по почте, затем по нику и регистрацию нового аккаунта с уникальным ником.
7. Только после успешной проверки всех существующих пользователей отключайте Google provider в Supabase.

ПРОВЕРИТЬ ПЕРЕД ПУБЛИЧНЫМ ЗАПУСКОМ:
- Политика и условия privacy.html / terms.html — заглушки! Замените юридически корректными текстами.
- Проверьте существующий триггер создания profiles из auth.users: он должен записывать minecraft_nickname из raw_user_meta_data.
- Если SQL unique index сообщает о дубликатах — исправьте существующие дубликаты вручную.
- Edge Function содержит проверку Origin, но она НЕ является полноценной защитой от автоматизированных запросов. Добавьте rate limit/WAF, CAPTCHA и мониторинг входов до публичного запуска.
- Этот пакет обновляет САЙТ. Безопасный вход в Minecraft ещё требует серверного плагина и закрытого доступа к серверу. Не включайте offline-mode ради обхода проверки.
- Ник должен быть закреплён за аккаунтом; существующее редактирование ника в профиле требует отдельной серверной проверки уникальности.
