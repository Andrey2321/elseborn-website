ELSEBORN v9 — НОВЫЙ ЛОГОТИП И ФОН «ОБО МНЕ»

1. Сохраните резервную копию GitHub-репозитория.
2. Откройте папку elseborn-website-main из архива.
3. Загрузите ВСЕ файлы и папки из неё в КОРЕНЬ GitHub-репозитория Elseborn (не загружайте саму внешнюю папку).
4. Подтвердите Commit changes. Дождитесь завершения GitHub Pages Deploy.
5. Откройте сайт и обновите Ctrl+Shift+R.

Изменения: утверждённый прозрачный логотип в верхнем меню на всех страницах; favicon.ico, favicon-32.png, favicon-192.png, apple-touch-icon.png; новый фон «Обо мне» с мягким переходом, встроенный в профиль.
Файлы Supabase и SQL НЕ изменялись, выполнять SQL не требуется.
Проверка: откройте profile.html и убедитесь, что виден новый фон справа в «Обо мне».
