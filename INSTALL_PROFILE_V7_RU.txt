ELSEBORN — PROFILE v7 / ДРУЗЬЯ / ДОСТИЖЕНИЯ

1. Сделайте резервную копию сайта.
2. Загрузите СОДЕРЖИМОЕ папки elseborn-website-main в корень GitHub репозитория.
3. Supabase Dashboard > SQL Editor > New query: откройте PROFILE_FRIENDS_SETUP.sql Блокнотом, скопируйте его СОДЕРЖИМОЕ, нажмите Run.
4. После публикации обновите сайт Ctrl+Shift+R. Зайдите в свой профиль.
5. Друзья: откройте другого пользователя через раздел «Пользователи» и нажмите «Добавить в друзья». Получатель принимает заявку во вкладке «Друзья» своего профиля.
6. Достижения: автоматически вычисляются от profiles.created_at: Страж 1 мес, Путник 3 мес, Искатель 6 мес, Хранитель 12 мес, Легенда Elseborn 24 мес.
7. Discord: привязка учётной записи НЕ включена в сборку. Для безопасной привязки потребуется отдельно настроить Discord OAuth в Supabase и Redirect URLs. Не путайте вход через Discord с привязкой к существующему аккаунту.

Проверка: тестируйте с двумя отдельными аккаунтами; проверьте отправку/принятие заявки, изменение описания и публикации.
