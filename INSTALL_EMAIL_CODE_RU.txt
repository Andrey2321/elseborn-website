ELSEBORN — подтверждение регистрации кодом

1. Загрузите содержимое этого архива в корень репозитория GitHub Pages, заменив старые файлы.
2. В Supabase → Authentication → Emails → Confirm sign up в шаблоне должен быть {{.Token}} (без дополнительных фигурных скобок).
3. В Supabase → Authentication → Sign In / Providers → Email должно быть включено подтверждение почты.
4. Зарегистрируйте НОВЫЙ тестовый аккаунт: после отправки формы появится окно ввода 8 цифр.
5. Введите код из нового письма и нажмите «Подтвердить аккаунт». После успеха откроется profile.html.
6. При перезагрузке страницы незавершённое подтверждение восстановится. Есть кнопка повторной отправки (Supabase может ограничивать частоту).

Примечание: ранее зарегистрированные, но не подтверждённые аккаунты могут требовать нового кода через кнопку повторной отправки.
Если Supabase возвращает ошибку, текст будет показан под полем кода.
